🟢 Use full Claude (paid API)
  1. Get a key at console.anthropic.com → API Keys — add ~$5 credit (this is separate from your Claude subscription).
  2. In the extension folder, run npm install once.
  3. Set the key and start the bridge:
    $env:ANTHROPIC_API_KEY="sk-ant-…"
    npm run bridge
This panel flips to 🟢 automatically once the bridge connects. Prefer no cost? Stay on 🔵 Free mode.
